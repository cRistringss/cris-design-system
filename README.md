# cris-design-system

The design system for the Cris website: where design decisions live. Started from the `starter-paper` kit in [web-style-guide](https://github.com/cRistringss/web-style-guide).

| File | What it is |
|---|---|
| `storybook.html` | Every colour, type size and component on one page. Open it first. |
| `assets/tokens.css` | All values: colours, fonts, sizes, radii, motion |
| `assets/components.css` | All components, built from tokens only |
| `assets/site.js`, `assets/fonts/` | Shared script and self-hosted fonts |
| `SKILL.md` | The design rules, written for Claude |
| `CLAUDE.md` | The context file for every chat and Claude Code session |
| `prototypes/` | Page designs from Claude chat, one file per page |

Website: [cris-website](https://github.com/cRistringss/cris-website).
